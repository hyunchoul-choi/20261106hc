고객 품질 지수 현황판 샘플 데이터

고객사별 in-process 지수 추이

제품별 월간 지수(ppm)와 고객 target 비교. 점선 = 고객 target

제품별 target 대비 수준 (최근월)

지수 ÷ target. 100% 초과 = target 초과

개입 대상 리스트 (초과·주의 제품)

행을 누르면 위 추이 차트가 해당 고객사로 바뀝니다. 초과폭이 큰 순서로 정렬.

※ 모든 수치는 시연용 샘플 데이터입니다. 지수 = 불량수 ÷ 사용수 × 1,000,000 (ppm), 고객사 단위는 사용수 가중. 상태 기준: 초과 = 최근월 지수 > target, 주의 = target의 90% 이상 또는 최근 3개월 연속 상승 중이며 85% 이상, 안정 = 그 외. 실제 데이터 연결 시 이 기준은 조정하세요.
